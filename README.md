# Аюроведа - мобильное приложение для изучения аюрведы

## 📱 О приложении

**Аюроведа** - это интерактивное обучающее приложение, посвященное основам аюрведической медицины. Программа предлагает систематизированный подход к изучению древней медицинской системы через тестовую методику.

## 🚀 Основные возможности

### 📚 Учебные материалы
- 15 тематических билетов
- 10 вопросов в каждом билете
- Постепенное усложнение материала

### 🎯 Система оценивания
- Прохождение билетов в любом порядке
- Получение сертификата после завершения всех билетов

### 🔍 Работа с ошибками
- Автоматический сбор ошибочных ответов
- Возможность повторного прохождения
- Статистика по ошибкам

### ⭐ Избранное
- Добавление вопросов в избранное
- Быстрый доступ к важным материалам
